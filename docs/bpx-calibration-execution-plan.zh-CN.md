# BPX 标定与复杂地形训练：详细执行计划

目标是减小执行器、站姿和接触模型造成的 sim-to-real 差异。近期保持 PPO，先把力矩—转速能力、动态响应和站姿做准；不同时叠加新算法和大范围 DR。本文是待执行计划，不代表已完成实机标定。

## 1. 当前依据与实验边界

- 当前训练执行器是固定 `30 Nm` 上限的隐式执行器，PD 为 `30/1`、armature 为 `0.003`。这些是配置值，不是实测结果。
- 初始 torso Z 和平地高度奖励目标均为 `0.48 m`，不能据此认定最佳站高。默认髋俯仰 `0.8 rad`、膝关节 `-1.5 rad`。
- 策略 50 Hz，物理步 200 Hz。策略保持目标位置，执行器在物理步计算输出。标定采样率应依据实际反馈通道和待辨识带宽确定。
- 当前 Actor 为 45 维、动作 12 维；先维持现有部署接口。
- 只有本体、没有加载台架时，先完成悬吊动态响应标定和厂商资料收集；完整加载包络、承重站姿和地面接触验证分别保留为独立验收项。

## 2. 阶段 A：接口与数据链路核对

预计 0.5–1 个工作日；以实际固件和 SDK 情况为准。先做只读记录，再做受控动作。

### A1. 确认关节映射与控制语义

本地 SDK 的 `include/motion_types.h` 按腿排列：FL 三关节、FR 三关节、HL 三关节、HR 三关节。训练配置按关节类型排列：四个 roll、四个 pitch、四个 knee。不能直接把两个 12 维向量互传。

按当前两个文件定义，读取 SDK 向量转为策略顺序的索引为 `[0,3,6,9,1,4,7,10,2,5,8,11]`；策略目标转为 SDK 顺序为 `[0,4,8,1,5,9,2,6,10,3,7,11]`。实现应按关节名称生成并校验映射，不能仅依赖这组数字。位置、速度、力矩、增益和动作均需一致。

逐关节核对名称、方向、零位和限位；先验证映射互逆，再在受控条件下逐关节检查。核对 SDK 的 PD 加前馈力矩语义，以及真实控制周期、超时行为和限幅位置。SDK 示例增益不作为本项目已标定增益。

### A2. 确认能读到什么

| 数据 | 本地 SDK 线索 | 实施要求 |
|---|---|---|
| 高频 q、dq、tau | `getJointPositionHighRate` 等 | tau 是否为真实输出力矩必须向厂商确认 |
| 高频包时间与序号 | `getJointStateTimestampHighRate`、`getJointStateSeqHighRate` | 检查重复、丢包、时间回跳和更新率 |
| 电机/驱动温度 | `getMotorTemperature`、`getDriverTemperature` | 普通温度组文档上限为 1 Hz，不能当成高速力矩反馈 |
| 电池总电流 | `getBatteryCurrent` | 不是逐关节相电流或 q 轴电流 |
| 逐关节电流、母线电压、限流状态 | 已核对头文件未见明确对应接口 | 向厂商确认其他接口，或采用合适的外部测量 |

普通 UDP 状态请求率接口允许 1–200 Hz；独立 HighRate 通道不受其控制。HighRate 的实际更新率仍需实测。getter 可能返回缓存；同一序号不能作为新样本重复计入，独立 getter 的读取也不自动保证来自同一包，优先使用原子快照或序号一致性检查。

记录主机单调时钟、设备时间、包序号、指令发送时刻、q/dq/tau、目标 q/dq/tau_ff、Kp/Kd、温度和可用电源数据。不同速率数据保留原始时间戳与新鲜度，缺失标为缺失，不补成零。记录固件、SDK、机器人编号和配置版本。

**交付与验收：** 接口说明、关节映射、静态日志、实际采样率/抖动/丢包报告；坐标和单位没有歧义。硬件额定电流、温度、速度、关节范围及停止条件从厂商资料确定，不从仿真上限推断。

## 3. 阶段 B：悬吊动态响应辨识

预计 1–2 个工作日，不含厂商接口排查。吊具固定机身、腿部不触地；先使用已确认的安全控制模式。紧急停止和通信超时后的动作依据厂商流程，不能把全部命令清零默认当作任意姿态下的安全停止。

### B1. 实验顺序

1. 保持姿态并记录静态噪声、关节偏差和温度基线。
2. 单关节小幅、平滑的阶跃或斜坡，观察跟踪误差、过冲和延迟。
3. 从低频开始做小幅正弦或扫频；频率和幅度依据反馈带宽、关节余量逐步扩展，避开限位和自碰撞。
4. 正反方向、不同工作姿态重复，其他关节保持已知控制状态。腿的重力与惯性耦合仍要考虑。
5. 全部关节做基础筛查；是否共享参数按型号、减速比和响应相似性决定，异常关节单独处理。

### B2. 推荐算法

先用指令—反馈相关性估计端到端延迟的初值，再用灰箱模型配合有界、稳健非线性最小二乘联合拟合。模型先保持简单：控制响应、等效惯量/阻尼、摩擦及必要的延迟；复杂摩擦和迟滞只有出现可重复残差时才加入。

如果缺少可信输出力矩，可先辨识位置/速度输入输出模型，服务于响应匹配。不能仅凭 q、dq 和不明来源 tau 同时宣称精确辨识电机力矩常数、惯量和摩擦；参数可能互相补偿。数值微分会放大噪声，预处理和验证要保留时间相位。

按完整实验轮次划分拟合/验证集，避免把同一段时间序列随机拆点。比较 q/dq 的 RMSE、延迟、幅频/相频响应和误差随方向/姿态的变化。

**交付与验收：** 原始日志、响应图、参数及适用范围；在留出实验上优于原始模型，且没有通过错误时间对齐或过度平滑隐藏误差。此阶段不产出完整承载力矩—转速上限。

## 4. 阶段 C：力矩—转速包络

### C1. 没有加载设备时

向厂商索取关节输出端曲线及减速比、测试电压、温度、正反方向、峰值持续时间和连续工况条件。把厂商曲线与自己的低负载数据分开标注。没有资料的区域标为未验证，不能用运动散点最大值补齐。

### C2. 有受控加载条件时

使用额定匹配的加载台架或测功装置，覆盖多个转速及负载点，记录可重复维持的输出及限流/温度条件；具体加载点和持续时间依据厂商限制。静态力臂/砝码仅用于静态或低速校核，测量需要考虑方向、重力矩及装夹误差。

区分驱动/制动、正反转、短时峰值/连续输出。生成带条件标签的边界图和原始工作点；悬吊空载速度不能证明高速负载输出能力。

### C3. 拟合与交付

优先查表插值或有约束的分段线性包络，分别得到 `tau_min(dq, conditions)` 和 `tau_max(dq, conditions)`；只在数据支持时使用低速平台加高速降额模型。普通最小二乘的平均曲线不是能力边界。未覆盖区域不外推更强能力。

用留出的速度点和实验轮次验证，报告测量不确定性及能力高估情况。交付峰值与连续曲线、适用电压/温度/持续时间、测量覆盖范围、机器可读参数。连续工况曲线不等于已建立热模型；若缺乏热参数，峰值用量和持续时间另行监控。

## 5. 阶段 D：仿真接入与复现

预计 1–2 个工作日，以完成数据为前提。

1. 将辨识参数和曲线集中存放，保留数据来源、单位、关节命名和版本。
2. 核对 Isaac Lab 项目固定版本的执行器实现；固定 `effort_limit_sim` 不能单独表达随速度变化的包络。需要自定义显式执行器时，重新验证隐式到显式 PD 的数值响应。
3. 每个物理步按当前关节速度更新边界并限幅；策略周期仍保持 50 Hz。延迟要区分整步与亚步精度，不把测出的毫秒值随意取成一整策略步。
4. 同步 MuJoCo 中原有固定 PD/固定限幅假设，保留坐标、动作尺度、增益、限幅和时序一致。
5. 在仿真复现悬吊实验的机身约束、重力和输入轨迹；与实机留出日志比较，再做自由机身站立和运动测试。

**验收：** 参考输入下响应误差下降；能力边界不凭空提高；无非有限状态、异常振荡；训练与对照部署使用同一版参数。若 tau 反馈未校准，力矩误差指标明确标为估算量对比。

## 6. 阶段 E：站姿高度选择

先做几何和仿真筛选，再安排承重验证。没有触地条件时，只完成前半段，不能把悬吊保持姿态视为站姿热负担验收。

1. 统一 torso 原点、地面和足底接触点定义，通过正运动学确认可行站高。
2. 在可行范围内设置低、中、高三个候选站姿，由逆运动学得到关节角；足端布局和载荷保持一致，避免深蹲、膝关节近伸直奇异位形及限位。不给未经几何核对的绝对高度。
3. 仿真比较静态站立、慢走和抬腿余量，筛掉明显不合适的候选。
4. 实机使用厂商支持的站高接口或已验证的受控姿态程序承重比较；保护吊具在正常站立时不承重，若分担载荷必须记录并区分结果。先短时确认，再按额定条件扩展观察，不以短时温升结论代替连续热稳态。
5. 同条件、重复比较每个关节的可信力矩 RMS/峰值、可用电流、温升速率、跟踪误差、饱和持续时间、限位余量、机身波动和滑足。

RMS 按有效时间段计算 `sqrt(mean(tau^2))`；不把正负力矩相互抵消。速度接近零时机械功率小，但电流和发热仍可能大。无逐关节电流时，用可信 tau、温度及整机电池电流作有限对照，不能虚构逐关节电流结果。

选择负担和运动余量兼顾的站高区间。复杂地形奖励相对局部支撑面的高度，允许跨越时短暂屈腿；当前 rough/stairs 已关闭平地的世界 Z 高度项，不能直接重新打开固定世界高度奖励。

实施时同步默认关节角、动作偏置、相对关节位置观测、初始化高度、站姿奖励和部署配置。改变默认角度会改变旧策略语义；不直接用旧 checkpoint 验证新偏置。

## 7. 阶段 F：常规 DR 与 PPO 对照训练

先固定 PPO 超参数，避免和电机模型、姿态一起改变。建议分组：

| 组别 | 变化 | 主要目的 |
|---|---|---|
| A | 原配置与原始检查点 | 回归参考；在更新后的真实能力评估模型上也单列其表现 |
| B | 标定执行器、原站姿，新训练 | 判断执行器修正影响 |
| C | 标定执行器、筛选站姿，新训练 | 判断站姿影响 |
| D | C 加经复核的常规 DR | 判断鲁棒性收益 |

现有 DR 包含摩擦/恢复系数、质量/载荷、质心、初始状态、观测噪声和推扰。B/C 可保留同一版现有 DR；若先做低随机化诊断，则另列诊断组，不能让 B/C 的 DR 不一致。D 只调整有依据的范围。

Kp/Kd、输出能力和延迟随机化目前作为待实现扩展，不宣称已经存在；围绕标定中心设置范围。质量与惯量、地面摩擦、输出能力与电压/温度等保持物理一致性。

先做平地站立/慢走，再做坡面、小障碍、台阶及混合地形课程。已有单独台阶模型继续保留；共享条件下比较专项模型和新模型。是否引入历史观测/HIM，等基础模型和任务课程验证后再判断。

## 8. 统一评估与退出条件

- 建议每个候选配置至少 3 个训练种子，并在相同地形、命令、负载和执行器评估模型上比较；训练预算不足时先筛选、再对入围配置复跑。此为建议实验设计，不是已完成次数。
- 训练范围内、训练范围外的速度/地形单列，避免把外推失败混进基线指标。评估关闭探索、保持规定的随机化与种子。
- 指标至少包括通过率/跌倒率、速度跟踪误差、滑足、关节 RMS/峰值、速度分布、饱和比例/最长连续饱和、关节余量和实机温升。通过率写明试验次数与不确定性。
- 与 A 比较时同时报告训练模型差异；公平的部署能力对比使用共同的标定评估模型。真实试验也保持地面、载荷、电池状态和初始温度可比。
- 数值误差目标在首轮基线后根据传感器精度和重复性设定，不提前承诺未经测量的百分比。必须满足已确认的硬件限制；主要任务指标不下降，执行器饱和/持续负担是否改善需独立报告。
- 完整实机验收依次为悬吊、受控站立、慢走、小障碍、台阶；前项通过才扩大范围。仅悬吊验收只能声明响应匹配。

每次输出原始日志、配置快照、Git 提交、拟合参数、图表、检查点与评估报告。原 `pretrained/` 归档保持不变，新标定和站姿建立独立实验目录。

## 9. 近期执行顺序

第一批先交付接口/映射清单和只读采集，第二批完成悬吊响应拟合并收集厂商曲线，第三批接入执行器模型和仿真站姿对比，最后再做承重站姿验证及平地/台阶训练。

没有加载设备不阻塞前两批和部分仿真工作，但完整力矩—转速边界保持未验证状态。采集和模型接入通常可按数个工作日排期；加载夹具、厂商资料、GPU 训练及连续热测试时间单独估算，不承诺固定总工期。
