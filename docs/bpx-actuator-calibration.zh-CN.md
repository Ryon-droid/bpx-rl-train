# BPX 电机标定、站姿与复杂地形训练调整

本方案将实测力矩—转速边界、合适的站姿高度和常规域随机化作为近期重点。先校准执行器与身体姿态，再比较复杂地形算法的收益。

逐阶段的实验步骤、数据接口、交付物和验收条件见[详细执行计划](bpx-calibration-execution-plan.zh-CN.md)。

## 1. 当前基线与待确认项

| 项目 | 当前仓库设置 | 如何理解 |
|---|---|---|
| 执行器 | `ImplicitActuatorCfg`，固定仿真力矩上限 `30 Nm` | 没有配置实测的随转速变化力矩包络 |
| URDF 限制 | `effort=30`、`velocity=20` | 单位分别为关节侧 Nm 和 rad/s；文件标称值不等于实测能力曲线 |

## 2. 优先测关节输出侧力矩—转速曲线

### 测量对象与条件

统一在减速器后的关节输出侧记录转速和力矩，避免把电机轴参数直接用于关节仿真。不同关节型号或减速比应分别标定，并检查同型关节之间的偏差。

建议记录同步时间戳、关节名称、目标位置/速度/力矩、实际位置/速度、配置的 Kp/Kd、反馈电流/力矩、电池或母线电压、电机温度和故障/限流标志。标明电流是相电流、q 轴电流还是母线电流，力矩反馈是传感器实测还是驱动器估算。未确认定义和校准关系时，不能将电流直接换算为可信输出力矩。

分别覆盖正反转，以及驱动和制动工况；区分短时峰值与持续输出能力，记录峰值允许持续时间。电压下降、温度上升和驱动器限流会改变可用包络，应保留这些条件。

### 悬吊与加载实验各自解决什么

悬吊实验适合检查关节方向、零位、跟踪响应、延迟、摩擦及低负载速度。腿部仍有重力和惯性耦合，拟合时要考虑姿态和其他关节运动。

完整的力矩—转速边界需要可测量、可控制的外部负载，例如测功机或合适的关节加载台架。单纯悬吊扫频不能证明高速下仍能输出标称峰值力矩；静态砝码/力臂测量只能提供静态或低速标定点。没有加载设备时，先索取厂商在明确电压、温度和持续时间条件下的曲线，作为暂定依据，并标注未实测区域。

### 推荐拟合方法

1. 在多个转速点逐步加载，记录可稳定输出的力矩和限制触发情况，而不是把普通行走中出现过的最大力矩当作能力上限。遵循设备额定限制，不以失控或长时间堵转作为测量方法。
2. 数据充分时，按方向和工况拟合有约束的分段线性包络，或使用查表插值；拟合关注可重复的能力边界，普通最小二乘拟合所有散点的均值不能直接得到边界。
3. 若实测支持“低速恒力矩、高速降额”，可用限流平台加降额段的简化模型；不能默认整条曲线线性，也不能默认正反向和制动能力相同。
4. 用留出的电压、温度或转速点验证预测，报告包络误差与实测覆盖范围；实测范围外保守处理，不外推更高输出能力。

控制响应、摩擦和延迟仍可用灰箱模型加非线性最小二乘拟合。能力包络拟合与响应参数拟合是两项不同工作，应分别验证。

### 如何用于训练

根据速度、方向及可用条件得到上下力矩边界，并在物理步限制关节输出：

```text
tau_applied = clip(tau_requested, tau_min(q_dot, conditions), tau_max(q_dot, conditions))
```

现有固定上限的隐式执行器不能仅靠修改一个常数表达实测包络。实现时需要验证所选执行器模型是否支持对应曲线；若改用显式执行器，需要同步校准 PD 响应与物理步更新方式，避免只改限幅却改变整体控制行为。训练和 MuJoCo 对照应采用一致的执行器模型假设。

评估同时报告关节转速分布、力矩 RMS、包络利用率与饱和持续时间。静态支撑时速度接近零，机械功率也接近零，但电流和发热仍可能很大，因此只看机械功率不足以评价关节负担。

## 3. 站姿高度按关节负担选择

较低的蹲姿可能增大部分关节的负载力臂和持续力矩；具体变化取决于腿部几何、足端位置和受力分配。应避免长期深蹲，也应避免为了升高机身而接近膝关节伸直、运动学奇异位形或关节限位。

先确认实机推荐站姿，用正运动学核对关节角与站高，再选择可行范围内的低、中、高几个候选姿态。在相同地面、载荷、电压和足端布局下，比较稳定站立与慢走：

- 实际机身相对支撑面的高度、膝关节弯曲余量、关节限位余量；
- 髋/膝持续电流或可信力矩 RMS、峰值、饱和时间及温升；
- 机身稳定性、足端滑动、跟踪误差和抬腿余量。

选择能兼顾负担、稳定性和运动余量的高度区间，而不是直接指定“越高越好”。实机对照可先用原控制器支持的站高设置或受控姿态测试，避免用未经重训的策略验证新动作偏置。

训练调整时同步检查默认关节角、动作偏置、初始化高度、站立姿态奖励和高度约束。复杂地形使用相对局部支撑面的高度区间或过低姿态惩罚，并允许跨台阶时短时屈腿；不能使用固定世界 Z 强迫机器人在台阶上维持绝对高度。仿真可使用地形真值构造训练奖励，不必因此增加实机 Actor 的输入。

改变默认关节角会同时改变残差动作和相对关节位置观测的含义，现有模型不能默认直接兼容。新姿态应建立新的训练配置与运行记录，并通过重新训练或经验证的迁移流程处理。

## 4. DR 保持常规，围绕标定值设置

近期采用摩擦、质量/载荷、质心、初始状态、观测噪声和适量推扰这些常规项。当前代码已包含这些类别，范围需结合 BPX 和目标地面复核。后续若增加 Kp/Kd、输出能力和延迟随机化，也应围绕实测响应设置范围，作为待实现项单独记录。

先验证标称动力学和执行器包络，再逐步增加随机化。没有依据时不扩大范围，不用极端 DR 掩盖系统性的模型误差；电压、温度和限流等有关联的因素应保持物理一致性。

## 5. 实施顺序与验收

1. 确认 SDK 反馈定义，采集悬吊响应数据，获取厂商曲线或安排加载测量。
2. 形成带电压、温度、方向和持续时间标签的力矩—转速图，以及控制响应/延迟参数和测量覆盖范围。
3. 比较候选站姿，选择具有支撑力矩和运动余量的站高与默认关节角。
4. 在单关节响应和站立测试中验证仿真模型，再训练平地与台阶新基线；常规 DR 分阶段加入。
5. 用相同地形、指令、种子集合和电机模型评估通过率、跟踪误差、滑足、关节负担和饱和，再判断是否加入 HIM 等估计器。

执行器、姿态、奖励或算法的变更应分组对比。现有台阶历史评估包含超出训练范围的指令，新基线应先在训练指令范围内评估，并将超范围测试单列。
