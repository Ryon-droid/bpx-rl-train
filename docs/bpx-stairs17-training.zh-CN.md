# 17厘米台阶强化训练

2026-11-05：目标由15cm调整为**17cm**。教师235维地形感知输入，后续盲学生900维本体历史输入，12维动作。当前未证明17cm教师、盲学生或实机达标。

## 课程和本轮修正

实际梯级4、6、8、10、12、14、16、17cm，踏面30cm，上下楼各半。任务为`bpx_stairs17_teacher` / `bpx_stairs17_blind`。

上轮15cm微调改善倒退下楼，但扰动倒退上楼从95/96下降到67/96，并出现低台阶回退。本轮先比较原16cm最终教师与15cm第500/1000/1500轮检查点，在相同种子2026、15/17cm、前后方向、训练随机化条件下，优先保留最弱一组表现较好的模型，再比较总体成功数及物理失败。此单种子筛选不代表正式资格测试。

- 纵向/横向/转向/混合/站立比例保持70/10/5/10/5%，纵向前后均衡；去掉上轮下楼地形80%倒退偏置。
- 初始覆盖全部八档。35%重置重采样最高三档14/16/17cm，其余遵循课程，保留低台阶练习。
- 纯纵向指令增加惩罚`2 * lateral_velocity_body² + yaw_rate_body²`，权重-1；横移、转向、混合和站立指令不施加此项。奖励使用仿真状态，不增加策略输入。
- 纯纵向晋级须沿命令符号在地形X方向走满3.3m，且终点横向偏移小于0.75m；失败/超时仍按原规则降级。其他运动模式保留原课程。
- 原30Nm/20rad/s执行器限制、原身体碰地/姿态失败阈值、随机化范围及其他奖励保留。

偏航惩罚和采样修正是有依据的试验，效果仍需复测；不能断言上轮退步仅由某一因素造成。

## 有界首轮强化

```bash
BPX_PYTHON=python bash scripts/run_stairs17_trial.sh \
  /absolute/path/selected_teacher.pt stairs17_balanced_v1 /absolute/path/results
```

512环境、1500轮、新优化器、固定学习率5e-5，每100轮保存，预计最终`model_1499.pt`。RTX2080SUPER旧任务实测约1.3s/轮，预计训练约35分钟，另加复测10～15分钟；启动须告知预计用时，再按当前实测速度更新。

脚本训练后自动评估精确17cm、±0.30m/s、标称及全部随机化、种子2026/2027/2028，每报告32次上楼+32次下楼首轮尝试；另测8/12/15cm前进/倒退回归。通过数、物理失败及横向偏移分别报告。

资格汇总使用`--height 0.17`，八组均至少95%通过才通过教师主门槛；还需审查物理失败及低台阶回归。缺报告、重复机器人或配置不匹配会拒绝汇总。未合格不自动训练盲学生。
